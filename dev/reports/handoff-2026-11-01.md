## 2. The four crash families (all diagnosed this session)

1. **`CopLogicBase._exit` with a state the brain does not own** (2026-10-31
   07:17, heist `auc`): `copbrain.lua` `set_logic` → `local logic =
   self._logics[name]` → `logic.enter(...)` with nil. Crash stack: `_exit` →
   `CopLogicTravel.upd_advance:915` (the `objective == nil` branch) →
   `CopBrain:update`. Non-cop brains (team AI, civilians) lack cop-only states.
   **Fix 8.57.11** (`df9546f`): wrapper on `CopLogicBase._exit` downgrades an
   unknown state to `idle`/`inactive`, raises `exit_missing_logic` /
   `exit_no_fallback` alarm + trace.
2. **Freed enemy nav tracker in the aim pass** (2026-10-31 11:03): access
   violation at `_upd_aim` `focus_enemy.nav_tracker:nav_segment()`. Mechanism:
   `AIAttentionObject:_register` stores `unit:movement():nav_tracker()`;
   `CopMovement:pre_destroy` destroys that tracker; attention objects keep the
   pointer. LIES ran the aim pass from the **movement** update
   (`CopBrain:check_upd_aim` via `CopMovement:_upd_actions`), outside the logic
   update that refreshes `attention_obj`. **Fix 8.57.12** (`f67323c`, `cef3fef`):
   `lies_enemy_tracker(focus_enemy, data)` helper returns the cached tracker only
   while `alive(focus_enemy.unit)`; every aim/cover/charge/retreat read goes
   through it; `_upd_combat_movement` bails on missing attention; dodge block
   gated on enemy liveness.
3. **Spooc combat movement → `_upd_pose` fail-fast** (2026-11-01 05:46, 06:03,
   06:09, heist `dinner`): 05:46/06:03 were `access violation`; 06:09 was
   `0xc0000409` with WER exception parameter `0x5` = `FAST_FAIL_INVALID_ARG`
   (invalid argument to an engine/CRT call; no crash reporter, hence "silent
   close"). Breadcrumbs localised it to `_upd_pose`; the 248.2 vanilla
   `_upd_pose` is 15 lines **without any raycast**, while LIES still ran a
   40-line version calling `CopLogicSniper._chk_stand_visibility/_chk_crouch_visibility`
   → `World:raycast(... target_pos = attention_obj.verified_pos ...)` twice per
   pose decision. **Fix 8.57.15** (`12a5f80`): `_upd_pose` ported to 248.2.
   Subsequent live session: cloaker ran the previously fatal chain 32× plus a
   full tackle with no crash.
4. **Latent ordering bug in our own code** (found 2026-11-01): `lies_enemy_tracker`
   / `lies_trace_window` were declared **after** two call sites inside
   `_upd_combat_movement`, so those references were nil globals (would throw on
   the charge branch). **Fix 8.57.17** (`a00fb98`): helpers moved to the top of
   the file; test asserts no `lies_*` local is used before its declaration.

## 8. Next work item — port `find_segment_doors`, restore door watching

**Facts already established (do not re-derive):**

- Vanilla 248.2 (`navigationmanager.lua`): `find_segment_doors(from_seg_id, approve_clbk)`
  returns raw Vector3 doors (`if door.x`), skips nav-link door objects, has no
  nil guards on missing segments.
- LIES (`lua/managers/navigationmanager.lua:35`): superset with 3rd arg
  `center_only`; handles **animated nav-link doors** (`alive(door)`,
  `not door:is_obstructed()`, `door:script_data().element`,
  `element:value("position")`, `element:nav_link_end_pos()`), verifies the link
  belongs to `from_seg_id` by creating/destroying a tracker
  (`_quad_field:create_nav_tracker(pos, true)`), returns raw end positions in the
  default branch and `{center, end_pos}` tables (plus averaged center) in
  `center_only`.
- Author history: LIES 6/6.2 (`15c25c6` 2022-10-19, `97adbd5` 2022-10-26);
  2025 sync `46a93f2`; fork nav-v6 ports `0e4709c`, `fd1bbcd`; contract fix
  `78dab8a` (AI-01 `_upd_aim` handles raw Vector3 doors; AI-02 default branch
  returns raw `nav_link_end_pos()`, `center_only` returns tables; removes the
  vanilla phalanx `mvec3_set` type-error route).
- Engine APIs all exist in 248.2: `door:is_obstructed()`,
  `door:script_data().element`, `element:value("position")`,
  `element:nav_link_end_pos()`, `_quad_field:create_nav_tracker(pos, true)`
  (game uses them at `navigationmanager.lua:730/906/1369` and Iter mirrors it).
- Intent to preserve: include nav-link doors vanilla skips, verify segment
  ownership, keep the 2-arg contract for every other caller, never change the
  phalanx path.

**Stages**

1. Contract tests first (fake `_quad_field`/segments): 2-arg returns only
   Vector3s, no tracker allocation; 3-arg `center_only` returns
   `{center[, end_pos]}`; disabled/absent segments skipped; callback receives
   neighbour ids; every tracker created is destroyed, including on early exits.
2. Port `find_segment_doors` as a strict superset; nil guards for missing
   `from_seg`/`neighbour_seg`; keep AI-02 shapes.
3. Restore door watching as a LIES layer, not an aim rewrite:
   `_get_expected_attention_position_LIES` (pre-port `_get_expected_pos` body,
   tracker-safe through `lies_enemy_tracker`) + a thin override of
   `CopLogicAttack._get_expected_attention_position` that bails when the tracker
   is dead and otherwise dispatches LIES when `not LIES.settings.highperformance`,
   vanilla's original otherwise. Keep the `check_upd_aim` liveness gate.
4. Restore `door_raw` counter/`[LIES-CHECK]` line and re-add it to
   `watch-channel.test.mjs` + `dev/reports/smoke-check-logging.md`.
5. Reviewer pass, gates, then in-game: bank-style heist with doors and Iter nav
